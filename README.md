# urbex-poland 🌶️

Interaktywna strona demonstracyjna / żartobliwa, prezentująca nietypowe zachowania i możliwości przeglądarek internetowych.

🌐 **Strona na żywo:** [https://urb3x.github.io/urbex-poland/](https://urb3x.github.io/urbex-poland/)

---

## ℹ️ O projekcie

Projekt powstał w celach humorystycznych oraz edukacyjnych (cyberawareness) – demonstruje, jak witryny internetowe mogą wchodzić w interakcję z przeglądarką (okna pop-up, powiadomienia, automatyczne pobieranie, efekty dźwiękowe).

> [!NOTE]
> Projekt jest całkowicie bezpieczny dla Twojego urządzenia. Nie zawiera złośliwego oprogramowania, a wszystkie mechanizmy służą wyłącznie zabawie i edukacji.

---

## 🚀 Uruchomienie lokalne

1. Sklonuj repozytorium:
   ```bash
   git clone https://github.com/urb3x/urbex-poland.git
   cd urbex-poland
   ```

2. Uruchom lokalny serwer testowy:
   ```bash
   python server.py
   ```
   lub uruchom plik `run.bat` (w systemie Windows).
